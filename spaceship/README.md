# Модификация корабля

- **↑ / ↓** увеличивают и уменьшают тягу, **← / →** поворачивают корабль. При выходе за край поля корабль появляется с другой стороны.
- Девять врагов движутся стаей, десятый кружит вокруг корабля на радиусе 142 пикселя. Он выделен золотым цветом.
- Время жизни растёт между столкновениями. При контакте с врагом или астероидом оно сбрасывается до нуля, даже если у корабля есть щит.
- Щит выдерживает одно столкновение и восстанавливается после 2,5 секунды без контакта. После столкновения без щита корабль возвращается в центр. Новый астероид появляется каждые пять секунд.
